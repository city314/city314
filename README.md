## 🚀 Featured Projects

All three are live in production. Source is private (client work), so the links below go straight to the running sites.

### 🏛️ [FlexiiDome](https://flexiidome.pages.dev/en/) · *client project — built & shipped end-to-end*

Marketing and quote-request site for a geodesic dome manufacturer (5m–30m event structures).
The interesting part is the CMS: content lives in **Google Sheets** and is served through a Cloudflare Pages function, so the client edits copy, products and pricing in a spreadsheet they already know — no admin panel to learn, no deploy to trigger. Includes a `/api/content-health` endpoint that surfaces CMS failures instead of silently rendering stale content.

`Cloudflare Pages` `Cloudflare Functions` `Google Sheets API` `i18n (EN/TH)`

### ⛺ [Wild Duck Glamping Tent](https://glampingtent.vn/) · *client project — build & delivery*

E-commerce catalogue for modular glamping tents sold to resorts and homestays. Five product categories, a quote-request flow for high-ticket items (160M–1.15B VND) where a cart checkout doesn't fit the sales cycle, and a full VI/EN storefront.

`WordPress` `WooCommerce` `PHP` `i18n (VI/EN)`

### 🔺 [VTG — Vuông Tròn Giác](https://vtg-website.biyeo126.workers.dev/) · *my agency — design + build*

Site for a multidisciplinary studio covering creative design, architecture, and digital optimization. Deployed on **Cloudflare Workers** so it runs at the edge with no origin server to maintain. Bilingual VI/EN with service, team, and FAQ sections.

`Cloudflare Workers` `Edge rendering` `i18n (VI/EN)`
